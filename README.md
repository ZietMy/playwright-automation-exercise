🎭 E2E Playwright Automation Framework with OpenAI Data Generator
Hệ thống kiểm thử tự động toàn diện (End-to-End) cho trang web e-commerce Automation Exercise, áp dụng mô hình Page Object Model (POM) kết hợp OpenAI API để tự động sinh dữ liệu kiểm thử và triển khai CI/CD Pipeline.

📌 Tính năng nổi bật (Key Features)
Page Object Model (POM): Thiết kế kiến trúc mã nguồn mô-đun hóa, dễ bảo trì và mở rộng.

AI Test Data Generator: Tích hợp OpenAI (gpt-4o-mini) tự động sinh dữ liệu kiểm thử thực tế và ngẫu nhiên.
CI/CD Integration: Tự động chạy test suite qua GitHub Actions mỗi khi có bản build/push mới.
Live Reporting: Tự động tạo và xuất bản Allure Report trực tiếp lên GitHub Pages.
Cross-Browser & Parallel Execution: Hỗ trợ chạy kịch bản song song trên trình duyệt Chromium/Chrome.

🛠️ Công nghệ sử dụng (Tech Stack)
Core Framework: Playwright (TypeScript)
AI Integration: OpenAI API
Reporting: Allure Report, Playwright HTML Report
CI/CD: GitHub Actions, GitHub Pages
Package Manager: npm
